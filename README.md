# sorkinren-sketch.github.io

Sorkin Ren 的个人作品集网站。

GitHub Pages 自动部署，访问地址：https://sorkinren-sketch.github.io

## 项目列表

### Daily English x10
从真实英语教学视频中提取句子和原声音频的英语学习工具。
- 目录：`projects/daily-english-x10/`
- 单文件 HTML，所有音频 base64 内嵌

### 故事鱼骨 · 叙事引擎
可视化故事逻辑构建工具，类 UE 蓝图设计。
- 目录：`projects/story-fishbone/`
- 包含 index.html + app.js + data.js

## 添加新项目

1. 在 `projects/` 下创建新目录
2. 放入项目文件
3. 在 `index.html` 中添加项目卡片
4. 推送即可
